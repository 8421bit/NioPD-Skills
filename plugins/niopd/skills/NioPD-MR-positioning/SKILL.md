# Market Positioning Skill

This skill develops clear market positioning through systematic competitive analysis.

## Theoretical Foundation

### Positioning Statement Template
> For [target customer] who [need], [product] is a [category] that [benefit]. Unlike [competitor], we [differentiator].

### Positioning Dimensions
- Price vs. Quality
- Features vs. Simplicity
- Broad vs. Niche
- Innovation vs. Reliability

## Instructions

### Step 1: Analyze Current Position
- How are we perceived today?
- What do customers say about us?

### Step 2: Map Competitive Positions
Create positioning map on key dimensions

### Step 3: Identify White Space
- Where is there opportunity?
- What positions are overcrowded?

### Step 4: Define Target Position
- Where should we be?
- How is it differentiated?

### Step 5: Create Positioning Statement
Apply template with specific details

**File path**: `02-reports/[YYYYMMDD]-positioning-v0.md`
