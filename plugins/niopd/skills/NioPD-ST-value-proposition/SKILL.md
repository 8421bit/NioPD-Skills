# Value Proposition Canvas Skill

This skill applies the Value Proposition Canvas to design and refine compelling value propositions that resonate with target customers.

## Theoretical Foundation

### Origin
The Value Proposition Canvas was developed by **Alexander Osterwalder** as a companion to the Business Model Canvas, detailed in "Value Proposition Design" (2014).

### Canvas Structure

**Customer Profile:**
- **Jobs**: What customers are trying to get done
- **Pains**: Negative emotions, risks, obstacles
- **Gains**: Positive outcomes customers desire

**Value Map:**
- **Products/Services**: What we offer
- **Pain Relievers**: How we address pains
- **Gain Creators**: How we deliver gains

### Fit Types
1. **Problem-Solution Fit**: Value map addresses customer profile
2. **Product-Market Fit**: Evidence that customers want it
3. **Business Model Fit**: Profitable and scalable

### When to Use
- Product positioning
- Go-to-market strategy
- Customer segment focus
- Competitive differentiation
- Messaging development

## Instructions

### Step 1: Create Customer Profile
**Jobs:**
- Functional jobs (tasks to complete)
- Social jobs (how they want to be perceived)
- Emotional jobs (how they want to feel)

**Pains:**
- Undesired outcomes
- Obstacles
- Risks

**Gains:**
- Required outcomes
- Expected outcomes
- Desired outcomes
- Unexpected outcomes

### Step 2: Create Value Map
**Products/Services:**
- Core offerings
- Supporting services
- Enablers

**Pain Relievers:**
- How we eliminate/reduce pains

**Gain Creators:**
- How we produce expected/desired gains

### Step 3: Achieve Fit
Check alignment:
- Do pain relievers address real pains?
- Do gain creators produce valued gains?
- Are products/services relevant to jobs?
