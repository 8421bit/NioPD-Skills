## 简介

NioPD 是专为 Claude Code 设计的 AI 驱动产品管理工具包，集成了 69 个智能化指令，覆盖从商业战略规划到产品交付运营的完整流程。本指南将帮助您快速上手，体验 NioPD 的强大功能。

### 核心价值

NioPD 不仅仅是一个工具，更是您的 AI 产品管理伙伴。Nio 通过以下方式改变您的工作方式：

- **智能引导**：采用苏格拉底式提问和第一性原理思维，引导您发现隐藏的洞察
- **方法论驱动**：内置产品管理界的经典方法论和最佳实践
- **文档驱动**：建立清晰的文档关联和追溯性
- **工作流加速**：自动化重复性任务，提升工作效率

## 环境准备

### 必需条件

在开始使用 NioPD 之前，请确保满足以下条件：

1. **安装 Claude Code**：确保已安装 Claude Code 0.2.0 或更高版本
2. **基本产品管理知识**：了解产品管理的基本概念和流程
3. **网络连接**：用于文档生成和部分分析功能

### 安装步骤

#### 1. 克隆存储库
```bash
git clone https://github.com/iflow-ai/niopd.git
cd niopd
```

#### 2. 在 Claude Code 中添加插件
```bash
# 打开 Claude Code
code .

# 添加本地市场
/plugin marketplace add .

# 安装插件
/plugin install niopd@niopd-marketplace

# 验证安装
/niopd:SYS:help
```

## 工作区初始化

### 执行初始化命令

使用以下命令初始化 NioPD 工作区：

```bash
/niopd:SYS:init
```

### 初始化过程详解

初始化过程将创建以下目录结构：

```
niopd-workspace/
├── sources/       # 思考源材料层（BS + DT 指令输出）
├── reports/       # 数据分析报告层（UR + MR + ST 指令输出）
├── docs/          # 决策文档层（PD + PO 指令输出）
└── plans/         # 执行计划层（PM 指令输出）
```

### 预期输出

初始化完成后，您将看到以下确认信息：

```

✅ 我还创建/更新了位于 `.claude-plugin/claude-plugin.md` 的工作原则文档，包含了全面的指导方针。
✅ 我还将在 `.claude-plugin/claude-plugin.md` 文件中添加您的首选通信语言。我将在所有未来的交流中使用 [用户语言偏好]。
✅ 我还为您的项目背景信息创建了项目上下文文档 `claude-plugin.md`。
✅ 我还把您的项目背景和目标添加到了 `claude-plugin.md` 文件中。
```

## 完整端到端示例

让我们通过一个完整的示例来演示 NioPD 的工作流程。

### 示例场景：移动端重设计项目

#### 1. 创建新项目立项

```bash
/niopd:BS:new-initiative "移动端重设计"
```

Nio 将引导您完成以下步骤：
- 项目背景和动机
- 目标用户和价值主张
- 成功标准和衡量指标
- 初步范围和约束
- 关键假设和风险

#### 2. 添加用户反馈

```bash
/niopd:BS:note "用户反馈说导航太复杂，考虑简化为3个主菜单"
```

#### 3. 分析用户反馈

```bash
/niopd:UR:feedback --for="移动端重设计"
```

#### 4. 生成 PRD 草案

```bash
/niopd:PD:draft-prd --for="移动端重设计"
```

## 四大工作原则

Nio 遵循四个核心原则确保高质量的协作：

### 1. 同理心倾听

**特点**：
- 充分理解您的观点和上下文
- 积极倾听，避免过早判断
- 通过开放式问题引导表达

**示例**：
```
"你能详细描述一下这个痛点的具体场景吗？"
"这个功能对用户来说最重要的价值是什么？"
```

### 2. 苏格拉底式提问

**特点**：
- 通过提问引导您自我发现
- 揭示知识差距和替代方案
- 深化理解和洞察

**示例**：
```
"你认为这个假设成立的原因是什么？"
"如果没有这个假设，还有其他可能的解释吗？"
```

### 3. 第一性原理

**特点**：
- 将问题分解到基本要素
- 从零开始重新构建解决方案
- 打破常规思维模式

**示例**：
```
"如果我们从最基本的用户需求出发，应该怎么做？"
"这个功能的核心价值是什么？"
```

### 4. 按需建议

**特点**：
- 仅在明确请求时提供具体建议
- 尊重自主性和自我决定权
- 提供多种选择而非单一答案

**示例**：
```
"我可以在某些方面提供一些见解。你想听听我的看法吗？"
"对于这个问题，我有几个不同的角度可以探讨，你想了解哪个方面？"
```

## 常见问题解答

### Q1: 我是产品管理新手，能用好吗？

**A**: 当然可以！NioPD 的设计初衷就是帮助新手成长。Nio 会通过引导式对话帮助您逐步掌握产品管理思维，而不是直接给出答案。

### Q2: 我需要联网才能使用吗？

**A**: 部分功能需要网络连接：
- **文档生成**：需要（调用 Claude API）
- **查看文档**：不需要（本地 Markdown 文件）
- **竞品分析**（`MR:competitor --url`）：需要（抓取网页）

### Q3: 如何自定义 NioPD？

**A**: 有三种扩展方式：
1. **`/niopd:SYS:new-command`** - 基于重复任务创建自定义指令
2. **`/niopd:SYS:new-agent`** - 创建专用 AI 代理
3. **`/niopd:SYS:new-memory`** - 记录个人工作习惯，Nio 会自适应

### Q4: 文档存储在哪里？

**A**: 所有文档存储在本地 `niopd-workspace/` 目录中：
- ✅ 完全控制数据
- ✅ 可用 Git 管理版本
- ✅ 可分享给团队
- ✅ 支持任何文本编辑器

### Q5: 如何切换语言？

**A**: 初始化时会询问首选通信语言，之后会在 `.claude-plugin/claude-plugin.md` 中记录您的语言偏好。

## 下一步行动

### 推荐的学习路径

1. **熟悉界面**：运行 `/niopd:SYS:help` 查看所有可用命令
2. **实践对话**：使用 `/niopd:BS:hi` 开始头脑风暴
3. **创建项目**：尝试 `/niopd:BS:new-initiative "我的第一个项目"`
4. **分析反馈**：添加用户反馈并运行分析
5. **生成文档**：体验 PRD 生成流程

### 实践建议

- **每日练习**：每天使用 15 分钟与 Nio 对话
- **项目实践**：选择一个真实项目进行练习
- **知识积累**：定期回顾生成的文档
- **持续学习**：探索不同领域的分析命令

### 获取帮助

- **内置帮助**：`/niopd:SYS:help`
- **工作流检查**：`/niopd:SYS:flow-check`
- **升级系统**：`/niopd:SYS:upgrade`
- **社区支持**：访问项目 GitHub 页面
